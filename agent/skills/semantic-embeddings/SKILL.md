# Навык: Семантический векторный поиск и память задач (`semantic-embeddings`)

Используй этот навык, когда руководитель или сотрудник обращается к ассистенту без точного ID поручения, ищет похожие проблемы в смежных отделах, анализирует повторяющиеся блокеры или запрашивает историю договорённостей по теме.

## Как устроен индекс эмбеддингов (Emb 64d)

- Каждая задача, сообщение сотрудника (`source`) и черновик решения (`decisionDraft`) индексируются в 64-мерном нормализованном векторном пространстве (`EMBEDDING_DIM = 64`).
- Векторизация сочетает:
  1. Морфологический стемминг русских слов.
  2. Символьные триграммы (`3-grams`) для устойчивости к опечаткам и падежным формам.
  3. Смысловые якорные измерения управленческих доменов (бюджет/ФОТ, закупки/ТЗ, препятствия/риски, перенос сроков, приёмка/проверка, протоколы/отчётность).
- Ранжирование вычисляет гибридный скор на основе косинусной близости (`cosineSimilarity`) и лексического пересечения основ.

## Протокол применения

1. Вызови инструмент `semantic_search` с текстом вопроса или описания проблемы.
2. Изучи возвращённый список `results` (поля `score`, `cosine`, `taskId`, `kind`, `snippet`) и при наличии `taskId` — список `similarTasks`.
3. В ответе руководителю опирайся только на подтверждённые записи из найденных задач и источников, явно указывая ID задачи и автора сообщения.
4. Не выдавай семантическую близость за доказанный факт: если найдено несколько похожих поручений, перечисли их ID и предложи выбрать нужное.
