# Frozen paired full-chain rubric

Three new synthetic, single-turn cases Q01–Q03; both routes use exactly the same fixtures and v6/protocol2 policy. No post-output tuning. Historical heldout is consumed, not reused here.

The independent judge receives opaque candidate labels, fixture questions/expectations and public job outcomes/citations; not model names, manifests, route labels, cost or provider receipts. Freeze the verdict file before revealing identities.

For each case record:
- technical state: completed / rejected / invalid / unavailable;
- fact and authority correctness, correct requester/speaker, requested result fulfilled;
- source/decision evidence coverage, no material unsupported claims or internal keys;
- useful final: true only when completed and all substantive requirements satisfied;
- minor style issues separately; concise case-specific reason and severity.

A safe rejection is safe but is not a useful answer. Runtime critic approval alone does not establish quality. Q02 needs both prepared-content source evidence and a genuine stored acceptance decision. Q03 must not promote delivery time or a rumor into current truth/authority.

Compare independently useful finals, unsafe assertions, malformed/rejected outcomes, then cost and latency per useful final. A zero useful-final denominator is undefined, never zero cost. Report actual paid cost once; any exact cached critic reuse is disclosed with original usage/cost separately for an uncached-equivalent estimate, not represented as a fresh independent judgment. The external caller must enforce separately authorized aggregate caps; a per-run limit is not the global budget gate.

Three cases are diagnostic, not evidence of general model superiority or complete Markus personality/memory. Same-model self-critique has correlated-error limitations. Sequential route order and tiny sample limit latency conclusions. Freechat persistent memory remains unimplemented.
