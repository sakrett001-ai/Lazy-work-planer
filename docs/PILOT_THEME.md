# Неоновая тема рабочего пилота

Отдельный последний CSS-слой `dist/pilot-theme.css` загружается **реальным** `/assistant/workspace`, а не только HTML-эскизом. Node и compatibility channel отдают его через существующий список статических ресурсов. Login, рабочее пространство, карточка/редактор/отчёт используют общую тёмную палитру; внутренний свет доски перенесён из принятого neon-v2.

Палитра: ink `#080d1b`, текст `#f0f5ff`, вторичный `#acbad3`, cyan `#55e6ff`, violet `#c4adff`, coral `#ff9aab`, mint `#87efc5`. Свет остаётся декоративным по краям, текст не светится. Цвет не заменяет подписи статуса/просрочки. Фокус, отключённые кнопки, reduced-motion и печать учитываются отдельно.

Это визуальная интеграция: серверная модель задач, права, статусы, сроки, источники и сохранённые отчёты не меняются. Пять демонстрационных «пульсов», выдуманные даты начала, будущая срочность и окончательное имя продукта не добавляются. Нет новых шрифтов, изображений, библиотек, внешних ресурсов или платных вызовов.

Проверки: `node --test tests/pilot-theme.test.mjs tests/delegation-journey-ui.test.mjs`, `npm test`, `npm run typecheck`. Journey исполняет настоящие UI/handlers/SQLite с двумя сессиями, включая сохранение и скачивание неизменяемого отчёта. DOM/CSS и расчёт контраста **не являются визуальной проверкой** desktop/mobile. Штатный браузер текущей среды не достигает loopback сервера; обход ограничений, tunnel и внешний hosting не выполнялись.
