# Нижний пульс карточек — выбранный вариант B

Локальный кандидат рабочего `prototype-ui.js`, не старого браузерного демо.
Пользователь выбрал вариант B «Бегущая запись» из `pulse-live-options-v2`:
новый след записывается, прежний остаётся на месте и затухает, перед
пишущей точкой есть пустое пространство. Статичная полная кривая с бегущим
бликом и масштабирование формы больше не являются движением карточки.

## Состояния

Серверные данные, ACL, фильтры и сортировка не меняются. `start` не считается
планируемым началом; `proposedDue` не заменяет утверждённый срок.

| Условие | Сигнал | Пауза/период начала комплексов | Цвет |
|---|---|---|---|
| Принято | статичная прямая | — | зелёный |
| На проверке | статичная прямая | — | фиолетовый |
| Запланировано, срок не близок | B, амплитуда .72 | 2,8 с | нейтральный |
| В работе, срок не близок | B | 1,8 с | зелёный |
| Есть препятствие, срок не близок | B, амплитуда .72, тонкий | 2,8 с | цвет препятствия |
| Внутри последних 24 ч до срока | B | плавно 1,5 → 1,25 → 1,05 с | жёлтый → оранжевый → красный |
| Срок наступил или прошёл | B | 1,05 с, ограничено | красный |

Для препятствия срочный срок так же сокращает период, сохраняя
тонкую линию и текст состояния. Review/done имеют приоритет над остаточным
blocker. Просрочка review остаётся текстом. Без срока срочность не выдумывается.
Предварительная шкала отображения использует существующее окно soon: 24 ч —
жёлтый, 12 ч — оранжевый, 0 ч — красный, между точками плавная интерполяция.
Это не новые состояния задачи и не изменение утверждённого срока. Перед
публикацией шкала должна быть явно показана пользователю. Название
«Препятствие» не изменено.
По умолчанию срок — 18:00 мск. Ровно в срок — «Срок наступил».

Форма одного комплекса фиксирована: .82 с, как в выбранном B. Меняются
интервалы между комплексами, но не его длительность. При смене периода
сохраняется текущая доля фазы; прошлые отсчёты не переписываются. Это
условная визуальная метафора состояния работы, не медицинское измерение.

## Отрисовка и доступность

Один общий RAF, максимум 25 кадров/с, только видимые карточки. DPR ограничен
двумя. Нет отдельных таймеров на карточку; Resize/Intersection/MutationObserver
обслуживают доску совместно. История сигнала ограничена восьмью секундами.
Ширина прохода — 3,8 с, затухающий след — 2,6 с, впереди остаётся пустота.
Canvas находится в собственной нижней полосе 26 px после кнопок и скрыт
от accessibility tree. Состояние и срок остаются обычным текстом.

«Заметил» влияет только на уведомление о непрочитанной версии, не на пульс.
Обновление срока раз в 15 с меняет конфигурацию без сброса фазы, фокуса и
ввода. Замена DOM карточки с тем же ID сохраняет её историю сигнала.
Удалённые карточки освобождаются; pagehide отключает RAF и наблюдателей.
Выключенный «Пульс», reduced-motion и скрытая вкладка останавливают RAF,
без догоняющего скачка после возврата. Выключенный пульс сохраняет статичный
кадр. Без canvas остаётся декоративный статичный SVG. Review/done всегда
используют спокойный SVG. Стрелка открытия — локальный inline SVG.

## Проверка

- `npm test`
- `npm run typecheck`
- `git diff --check`
- `node scripts/preview-card-pulse.mjs /tmp/pulse-card-preview`

Последняя команда создаёт `index.html` и `archive.html` из реального renderer
с вымышленными карточками. Нет пользователей, приглашений, серверного API
или обработчиков рабочих действий. Визуальное состояние кнопок сохранено;
работает только переключатель движения и тот же локальный motion controller.
Внизу — эмблема в размерах 16/24/32/48 px.

DOM/модельные тесты не заменяют браузерную приёмку выбранного движения B:
новый след, затухание старого, пустой участок впереди, различимая частота,
неподвижный текст, отсутствие перекрытий, выключенный пульс, узкая доска.
Публикация требует отдельного разрешения. Предыдущие записи fixed-path glint
не являются доказательством приёмки этого варианта B.
